# РАНДОМ СИТИ — Telegram Mini App (v2 «Тебе пишут»: миссии-переписки, 45 сюжетов × переменные, RU + EN)

Челленджи для GTA 6: рандом выдаёт роль, задание, ограничение и «печать», игрок выполняет и растёт в ранге.
Полная концепция — в `PRODUCT.md`.

## Что внутри

| Файл | Что это | Править? |
|---|---|---|
| `data/missions.js` | **Все роли, задания, ограничения, печати** | Да, это твой основной файл |
| `config.js` | Название, имя бота, ссылка на канал | Да, один раз |
| `app.js` | Логика приложения | Нет (проси Claude) |
| `index.html`, `style.css` | Внешний вид | Нет (проси Claude) |

v0 работает **без сервера**: прогресс игрока хранится в облаке Telegram (CloudStorage). Мы не собираем персональные данные — поэтому для v0 не нужен российский сервер.

## Запуск за 20 минут

### Шаг 1. Создай бота
1. В Telegram открой **@BotFather** → `/newbot`.
2. Имя: `Рандом Сити` (или твоё). Юзернейм: например `random_city_bot` (должен кончаться на `bot`).
3. Сохрани юзернейм — он нужен в `config.js`. Токен **никому не показывай**, для v0 он не нужен.

### Шаг 2. Выложи приложение на GitHub Pages (бесплатно)
1. На github.com → **New repository** → имя `random-city` → **Public** → Create.
2. Загрузи туда все файлы из этой папки (кнопка *Add file → Upload files*) — или попроси Claude запушить.
3. В репозитории: **Settings → Pages → Branch: main, папка / (root) → Save**.
4. Через 1–2 минуты появится адрес вида `https://ТВОЙ_ЛОГИН.github.io/random-city/` — открой и проверь.

### Шаг 3. Подключи приложение к боту
1. В @BotFather: `/newapp` → выбери бота → название, описание, картинка 640×360.
2. URL: адрес из шага 2.
3. Short name: `play` (это `APP_SHORT_NAME` в `config.js`).
4. Ещё сделай кнопку меню: `/mybots` → бот → **Bot Settings → Menu Button** → тот же URL.

### Шаг 4. Заполни `config.js`
```js
BOT_USERNAME: "random_city_bot",
APP_SHORT_NAME: "play",
CHANNEL_URL: "https://t.me/твой_канал",
```
Загрузи изменённый файл в GitHub — сайт обновится сам за минуту.

### Шаг 5. Проверь
Открой бота → кнопка меню → крути задание → «Вызвать друга» → отправь себе в «Избранное» → открой ссылку. Должно выпасть то же самое задание.

## Как добавить задание
Открой `data/missions.js`, скопируй строку похожего задания, поменяй `id` (уникальный!) и текст:
```js
{ id: "t_my_new", lvl: 2, t: "Текст задания", uses: ["car"] },
```
- `lvl`: 1 лёгкое, 2 среднее, 3 хардкор
- `uses`: что нужно для задания — `car`, `bike`, `boat`, `air`, `weapon`, `foot`, `wanted`, `travel`. Генератор сам не даст несовместимое ограничение (например, «без машин» к угону машины).
- **Никогда не меняй `id` уже выпускавшихся заданий** — сломаются старые дуэльные ссылки.
